# ServiChile.cl

Plataforma de verificación oficial de identidad y auditoría patrimonial en Chile. Ofrece seguridad patrimonial, detección de fraudes y scoring de riesgo con datos del Estado chileno cumpliendo normativas vigentes.

## Estructura

- `index.html`, `productos.html`, `precios.html`, `contacto.html`, `blog.html` - Páginas principales
- `css/styles.css` - Sistema de diseño completo
- `js/main.js` - Funcionalidades JavaScript
- `.git` - Control de versiones
- `.vercel` - Configuración de despliegue

## Uso

Abre `index.html` en navegador o usa: `python -m http.server 8000`
